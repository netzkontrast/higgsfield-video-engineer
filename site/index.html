Higgsfield Video Engineer Source on GitHub
Code-based films

Short animated films where every frame is drawn by code.

The characters, the set, the movement and the sound are all written as code. Our own renderer turns that code into pictures on your computer's graphics card. An AI agent can run the whole process, from the story to the finished video.

What makes it different

Runs on your own computer

No accounts and no cloud. Mac, Windows and Linux. Renting faster GPUs online is optional.

Everything is our own

No outside 3D software. Felt, paper, clay, glass, smoke, blur and soft focus come from our own path tracer.

Safe to stop and restart

Every frame is a pure function of its number, so a render can stop at any time and continue later, or redo one frame.

Made for AI agents

One install gives an agent the renderer, the tools and the step-by-step process.

From story to delivered film

Each step has a gate. Generated images are only a target to compare against; they never appear in the film.

  1. Story
  2. Music and bar map
  3. Beat sheet
  4. Styleframes
  5. Assets in code
  6. Animatic
  7. Notes pass
  8. Light and look
  9. Final render
  10. Post and sound
  11. QA
  12. IP check and delivery

Get started

You need Node.js 22.12 or newer, Google Chrome and FFmpeg. Python 3.11+ is optional.

# check your computer, then make a test picture
git clone https://github.com/higgsfield-ai/higgsfield-video-engineer
cd higgsfield-video-engineer
bin/hve setup
bin/hve hello

# the 20-second example film: a quick preview with title and sound
bin/hve example --quality preview --encode

# start your own film
bin/hve new my-film
